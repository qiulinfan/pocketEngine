Built-in Components

Built-in components are first-class Lua classes and can also be added through the editor or actor:AddComponent(type_name).

Transform

Properties

  • actor
  • key
  • enabled
  • x
  • y
  • rotation

Transform stores local transform values. World transform is derived by the engine and is not directly exposed as writable Lua properties.

Methods

Method Description
SetSpriteCell(row, column) Convenience setter for sprite_row / sprite_column

Notes

  • sprite is the image resource name, for example images/Run.png
  • spritesheet slicing comes from project metadata in .engine/project/spritesheets.json
  • custom gameplay components can store sub-sprite references as encoded strings, but SpriteRenderer itself still uses separate row / column fields
