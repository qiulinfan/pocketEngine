1. The system font for the UI of PocketEngine is "Inter". A modern, clean, nice open source font.
Source: https://github.com/rsms/inter

2. The example game "ball game" is an open source A2 game. source: https://a2engine.org/

3. Dear ImGui is vendored directly into thirdparty/imgui for editor UI and docking support.
Source: https://github.com/ocornut/imgui

4. ImGuizmo is vendored directly into thirdparty/imguizmo for editor gizmo support.
Source: https://github.com/CedricGuillemet/ImGuizmo
