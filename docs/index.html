PocketEngine

Cross-platform 2D runtime + editor, built as a variant of A2 Engine.

PocketEngine is written in C++17 on top of SDL2, Lua, Box2D, Dear ImGui, and JSON scene assets. The current editor includes a docked Scene view, embedded runtime Viewport, Project browser, Hierarchy, Inspector, and live play-mode mutation workflow.

Variant from A2 Engine.

Watch MP4 Demo View Repository

Editor

  • Scene view with editor camera, zoom, pan, picking, and drag-move
  • Viewport for pure runtime output and input routing
  • Hierarchy, Inspector, Project, and Status panels

Runtime

  • Lua-hosted gameplay scripting
  • Scene mutations and scene-backed stable actor UIDs
  • Parenting with local/world Transform and physics hierarchy inspection

Build

  • CMake is the single source of truth
  • Visual Studio, Xcode, Ninja, and Unix Makefiles generators
  • Vendored third-party dependencies inside thirdparty/
